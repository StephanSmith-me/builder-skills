# What to compare

Use this list while comparing. The decision of which group a name belongs in is in `SKILL.md`.

## Files

- `.env`, `.env.local`, `.env.development`, `.env.production`, and other `.env.*` files in the repo.
- A gitignored file still counts. Ask the user to point at it if you cannot read it.

## Names, not values

- Record the name on the left of `=`.
- Do not print, copy, or repeat the value.
- Search application code. Skip the env file itself, lockfiles, and this skill.
