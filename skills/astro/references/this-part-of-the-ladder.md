# This part of the ladder

The ladder is in `SKILL.md`. Do not score islands, view transitions, or a host.

Playbook, only if you need Astro's own wording: https://stephansmith.me/tools-i-use/entry/astro/
Use only: When to reach for it, Watchouts. Do not invent a setup from the rest of the page.

## What counts

- Front matter is the field block at the top of a markdown or MDX content file. Quote the path. The code at the top of an `.astro` page does not count.
- A content type is a definition that groups those files and names the fields they share. An Astro content collection counts. Quote the config. A folder of markdown with no definition does not.
- Both can be missing. Stop at the first missing step.

## How far to push

- A few Astro pages and no content files: stay on pages. Front matter is not the gap yet.
- Many entries of one kind, or two kinds such as posts and docs, with front matter and no type: the content type is the next step.
- A content type already in the config: this part of the ladder is in place. Stop. Do not add a CMS.
