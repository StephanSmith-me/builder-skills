# Which host

The choice is in `SKILL.md`. Two hosts. Do not add a third.

## GitHub

Use this for an HTML site while the project is still that simple.

- Free hosting for the site.
- Good for this stage. It is not a lack of ambition.
- Once you have named GitHub, stop. The folder, branch, and sourcemap looks are the `github` skill.

## Cloudflare Pages

Use this when the project will grow past one HTML site.

- Pages is free to start.
- The reason to choose it is the feature ecosystem that becomes useful as they grow, not a better price today.
- Once you have named Cloudflare, the tunnel, Pages, and Workers review is the `cloudflare` skill. Do not do that review here.

## Also notice

- Do not create the repo, and do not deploy, until the user says to.
- A host they already use can be the right one. Say so when it matches the stage. Do not move a simple HTML site onto Cloudflare because the ecosystem exists.
