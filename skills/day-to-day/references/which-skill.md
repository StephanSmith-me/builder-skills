# Which skill

The review is in `SKILL.md`. One part of the host that ships the app. Do not re-walk the rest.

Bring back the preview and the deploy Action. Cloudflare Pages or Workers is `cloudflare`. Render is `render`. Tunnels, Pages, and Workers are the Cloudflare skill when they ask for the full setup. What Render runs is the Render skill when they ask for that.

The public page asks how code is packaged, seen on staging, and deployed. The preview and the deploy Action are the part this skill answers. Do not invent a second pipeline. Do not assume Cloudflare when the files show Render, or the reverse.
