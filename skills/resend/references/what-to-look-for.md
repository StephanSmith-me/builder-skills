# What to look for

The report is in `SKILL.md`. Do not send mail, and do not invent a Resend dashboard setting you did not open.

## The key

- `.env` counts when you opened the file and saw the setting name.
- Infisical counts only when that project is open. Closed is unseen, not missing.
- A key written into source is the finding to say first. Never print the value.

## Templates

- In the code: the body, or a template id, inside the process that sends.
- In env: a setting whose name is the template. Name it. Do not print it.
- Both can be true. Say both.
- No template in either place means you did not see one. Do not assume a hosted template exists.

## The signal

Resend is a common go-to when someone vibe-codes an app. The key or the send call is enough for the signal. It suggests how the app may have been started. It does not label the person, and it is not a reason to switch to Postmark.

Postmark does the same job. Two senders is a mix. Do not migrate one onto the other until the user says to.
